# Support

Use [GitHub Issues](https://github.com/lemkyz/Aegis/issues) for reproducible bugs and focused feature requests.

Include the Aegis version, VS Code version, operating system, backend health response, the command you ran, and the smallest safe reproduction you can share.

Do not paste credentials, private source code, production logs, or vulnerability details that could put users at risk. Follow the [security policy](https://github.com/lemkyz/Aegis/security/policy) for private reports.
