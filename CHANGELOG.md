# Changelog

All notable changes to Aegis are recorded here.

## 0.2.0 — 2026-07-27

This release connects the first complete Aegis trust workflow.

### Added

- production task planning and execution with append-only audit events
- deterministic secret, dependency, and attack-surface specialists
- primary-model review, independent verification, and consensus
- evidence-backed threat-model composition
- explicitly authorized dynamic validation in a hardened local container
- transactional secure fixes with static rescan and baseline replay
- immutable project security memory and deterministic policy output
- Trusted Analysis in VS Code
- source, plan, audit, and artifact-manifest SHA-256 attestations
- cancellation, timeout, repository-drift, and integrity failure handling
- real Git repository acceptance coverage and a single release-readiness gate

### Release surfaces

- VS Code extension
- GitHub pull-request action
- local CLI
- local FastAPI backend
