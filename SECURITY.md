# Security Policy

Report security vulnerabilities privately.

**security@aegistrustlayer.com**

You may also use GitHub private vulnerability reporting when it is enabled for this repository.

Include the affected version, platform, reproduction steps, impact, and relevant logs with secrets removed.

Do not include production credentials, customer secrets, or data you are not authorized to share.

Controlled validation must only be used on code, repositories, containers, and systems you own or are explicitly authorized to test.
