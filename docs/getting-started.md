# Getting started

Aegis is currently distributed primarily through its VS Code product surface.

## VS Code

Install Aegis from the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=aegis-security.aegis-security).

Open a local project, then use the Aegis commands from the Command Palette.

Aegis may require a trusted local workspace for repository-sensitive actions.

## What to expect

The product separates security findings from verification. A workflow may
finish with a verified, partial, unavailable, or inconclusive result depending
on what could actually be checked.

Aegis should not present an incomplete verification as a clean result.
